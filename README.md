## Engineering Direction

I am interested in the gap between an impressive model response and a dependable product. My projects explore how retrieval, state, tools, and interface design work together to make AI systems useful.

The problems I keep working on:

- **Evidence-grounded answers**: retrieving relevant information, checking sources, and recognising when there is not enough evidence to answer.
- **Controlled agent workflows**: combining flexible model behaviour with explicit steps, validated inputs, and clear failure paths.
- **State and recovery**: keeping user data consistent across long conversations, interrupted requests, and retries.
- **Human-facing software**: making complex systems understandable through clear interfaces, explanations, and accessible interactions.
